Keeps your Taxi Peninsula bookings and records visible when the theme is not active, and exports them as CSV.

== Description ==
The booking system lives in the Taxi Peninsula theme. If the theme is ever switched off, WordPress stops showing its bookings, quotes, incidents and other records (the data stays in the database). With this plugin active they stay listed under "Taxi data", read-only, until you switch the theme back on.

Tools → Taxi data export downloads any record type as a CSV file at any time.
